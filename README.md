# Sofiya Arbani — Portfolio

A responsive, single-page portfolio for Sofiya Arbani, an Electronics & Telecommunication Engineering graduate interested in entry-level opportunities in the business domain.

## Features
- Editorial pastel design with a responsive mobile layout
- Scroll-triggered reveal transitions
- Custom abstract monogram artwork with pointer-responsive 3D tilt
- Reduced-motion accessibility support
- Academic projects, skills, education, and recruiter contact sections
- Semantic HTML, CSS, and vanilla JavaScript; no build step required

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** from the sidebar.
3. Under the build and deployment section, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the site; the published URL will appear in the Pages settings.

## Content
Education, skills, contact information, and academic project descriptions are based on the supplied CV. Project descriptions summarize academic work and do not claim production deployment.
